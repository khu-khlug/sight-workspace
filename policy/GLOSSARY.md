# 정책 용어 사전

정책 문서에서 사용하는 비즈니스 용어의 표준 표현과 정의를 관리한다.

| 표준 용어 | 정의 | 색인어 |
| --- | --- | --- |
| 회원 | 동아리 활동을 위해 사이트에 등록된 사람 | 사용자, 구성원 |
| Info21 인증 | 경희대학교 Info21 계정으로 회원 본인과 학적 정보를 확인하는 절차 | 학교 인증, 종정시 인증 |
| 인증 회원 | Info21 인증을 완료한 회원 | 인증된 회원 |
| 명예 회원 | 졸업한 회원에게 부여되는 회원 분류 | 졸업 회원 |
| 교류 회원 | 동아리와 교류하는 단체의 구성원으로 사이트에 등록된 회원 | 교류 단체 회원 |
| 운영진 | 동아리 운영을 담당하는 구성원 | 임원 |
| 경험치 | 회원의 동아리 활동에 따라 누적되는 활동 점수 | ExPoint, 포인트, 활동 포인트 |
| 경험치 조정 | 회원의 경험치를 증가 또는 감소시키고 그 근거를 기록하는 행위. 양수 값을 적용하면 경험치 부여, 음수 값을 적용하면 경험치 차감이다. | 포인트 조정, 경험치 변경 |
| 경험치 부여 | 양수 값을 적용하여 회원의 경험치를 증가시키는 경험치 조정 | 경험치 지급, 포인트 지급 |
| 경험치 차감 | 음수 값을 적용하여 회원의 경험치를 감소시키는 경험치 조정 | 경험치 회수, 포인트 차감 |
| 그룹 | 회원이 함께 동아리 활동을 수행하고 관리하는 협업 단위 | 프로젝트, 스터디, 운영 그룹 |
| 그룹 구성원 | 특정 그룹에 현재 참여하고 있는 회원 | 그룹 멤버 |
| 그룹 카테고리 | 그룹의 활동 목적과 운영 성격을 구분하는 분류 | 그룹 종류, 그룹 유형 |
| 그룹 상태 | 그룹이 현재 활동 중인지, 중단되었는지 또는 종료되었는지를 나타내는 분류 | 그룹 진행 상태 |
| 내 그룹 | 특정 회원이 현재 그룹 구성원으로 참여하고 있는 그룹 | 참여 그룹 |
| 공식 그룹 | 교육, 프로그램 또는 운영 카테고리에 속하는 그룹 | 교육·프로그램 그룹 |
| 자율 그룹 | 스터디, 프로젝트 또는 문서화 카테고리에 속하는 그룹 | 자율 연구 그룹, 연구 그룹 |
| 진행 그룹 | 그룹 상태가 진행인 그룹 | 활동 중 그룹 |
| 성공 그룹 | 그룹 상태가 종료(성공)인 그룹 | 성공 종료 그룹 |
| 지원 신청 | 회원이 동아리 활동에 필요한 지원을 운영진에게 요청하는 기록 | 지원 요청, LAB 지원 신청 |
| Discord 연동 | 회원의 사이트 계정과 Discord 계정을 연결한 상태 | 디스코드 연동 |
| 운영 알림 채널 | 지원 신청과 같이 운영진의 확인이 필요한 사건을 알리기 위해 사용하는 Discord 채널 | 운영 채널, 운영진 알림 채널 |
