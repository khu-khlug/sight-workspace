# 경험치 조정량 정책

## 적용 범위

이 문서는 회원의 활동에 따라 자동으로 적용하는 경험치 조정의 사유, 대상 회원 및 경험치 조정량을 정의한다. 자동 경험치 조정이 필요한 다른 정책은 이 문서를 참조하며, 경험치 조정량을 따로 정의하지 않는다.

## 정책

### 자동 경험치 조정의 기준

- 자동 경험치 조정은 아래 각 활동에 정의한 사유가 발생한 경우에만 적용한다.
- 각 사유가 발생하면 정의한 대상 회원에게 정의한 경험치 조정량을 적용한다.
- 대상 회원이 여러 명인 경우 각 회원에게 같은 경험치 조정량을 적용한다.
- 새로운 사유는 각 활동에 적은 포함 기준에 따라 해당하는 활동에 추가한다.
- 사유가 여러 활동의 포함 기준에 해당하면 그룹 활동, 게시판 활동, 회원 활동, 방문 활동 순서로 먼저 해당하는 활동에 추가한다.
- 어느 활동의 포함 기준에도 해당하지 않는 사유는 새로운 활동과 그 포함 기준을 먼저 정의한 뒤 추가한다.

### 그룹 활동

- 특정 그룹 또는 특정 그룹에 속한 대상에서 발생하여, 그 그룹을 특정해야 사유를 설명할 수 있는 경우를 포함한다.

| 사유 | 대상 회원 | 경험치 조정량 |
| --- | --- | --- |
| 그룹을 만듦 | 그룹을 만든 회원 | +50 |
| 그룹에 참여함 | 참여한 회원 | +40 |
| 그룹에서 나갔거나 내보내짐 | 나가거나 내보내진 회원 | -40 |
| 그룹이 성공으로 종료됨 | 그룹 구성원 전체 | +90 |
| 그룹이 실패로 종료됨 | 그룹 구성원 전체 | +70 |
| 성공으로 종료된 그룹이 다시 진행됨 | 그룹 구성원 전체 | -90 |
| 실패로 종료된 그룹이 다시 진행됨 | 그룹 구성원 전체 | -70 |
| 포트폴리오를 발행함 | 그룹 구성원 전체 | +10 |
| 포트폴리오 발행이 취소됨 | 그룹 구성원 전체 | -10 |
| 세미나 발표를 등록함 | 그룹 구성원 전체 | +150 |
| 세미나 발표 등록을 취소함 | 그룹 구성원 전체 | -150 |
| 운영진이 세미나 발표 등록을 취소함 | 그룹 구성원 전체 | -150 |
| 활동보고서를 제출함 | 그룹 구성원 전체 | +150 |
| 활동보고서 제출을 취소하거나 삭제함 | 그룹 구성원 전체 | -150 |
| 카드를 만듦 | 카드를 만든 회원 | +1 |
| 카드에 기록을 작성함 | 기록을 작성한 회원 | +2 |
| 카드를 삭제함 | 카드를 만든 회원 | -1 |
| 기록을 삭제함 | 기록을 작성한 회원 | -2 |
| 삭제된 카드를 복구함 | 카드를 복구한 회원 | +1 |
| 삭제된 기록을 복구함 | 기록을 복구한 회원 | +2 |

### 게시판 활동

- 게시판 또는 게시판에 속한 대상에서 발생하여, 그 게시판의 대상을 특정해야 사유를 설명할 수 있는 경우를 포함한다.

| 사유 | 대상 회원 | 경험치 조정량 |
| --- | --- | --- |
| 게시판에 게시글을 올림 | 게시글을 올린 회원 | +5 |
| 게시판에 댓글을 올림 | 댓글을 올린 회원 | +1 |
| 게시판에서 게시글이 삭제됨 | 게시글을 올린 회원 | -5 |
| 게시판에서 댓글이 삭제됨 | 댓글을 올린 회원 | -1 |

### 회원 활동

- 회원 자신의 자격이나 상태가 바뀌는 것 자체가 사유인 경우를 포함한다.

| 사유 | 대상 회원 | 경험치 조정량 |
| --- | --- | --- |
| 회원 등록이 승인됨 | 승인된 회원 | +1000 |
| 회비 납부가 확인됨 | 회비를 납부한 회원 | +100 |
| 회원의 접속이 차단됨 | 차단된 회원 | -1100 |
| 회원의 접속 차단이 해제됨 | 차단이 해제된 회원 | +800 |

### 방문 활동

- 무언가를 만들거나 바꾸지 않고 회원이 특정 장소에 출입하거나 접속한 사실만으로 발생하는 경우를 포함한다.
- 방문 활동의 각 사유는 한 회원에게 하루에 한 번만 적용한다.

| 사유 | 대상 회원 | 경험치 조정량 |
| --- | --- | --- |
| 동아리방에 출입함 | 출입한 회원 | +2 |
| 사이트에 접속함 | 접속한 회원 | +1 |
