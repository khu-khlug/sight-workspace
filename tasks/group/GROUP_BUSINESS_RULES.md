# 그룹 시스템 — 기능 목록 및 비즈니스 규칙

> 기술적 구현 세부사항을 배제하고, 도메인 지식과 비즈니스 규칙에 집중하여 정리한 문서입니다.

## 1. 그룹 개요

그룹은 KHLUG의 핵심 협업 단위로, **리스트 > 카드 > 기록**의 3계층 칸반 보드 구조로 활동을 관리합니다.

---

## 2. 그룹 분류 체계

### 카테고리

| 카테고리 | 설명 | 누가 만들 수 있나 |
|----------|------|-------------------|
| 스터디 | 학습 목적 그룹 | 일반 회원 |
| 프로젝트 | 프로젝트 수행 그룹 | 일반 회원 |
| 문서화 | 문서화 목적 그룹 | 일반 회원 |
| 운영 | 학회 운영 그룹 | 운영진만 |
| 교육 | 교육 프로그램 그룹 | 운영진만 |
| 프로그램 | 프로그램 그룹 | 운영진만 |

### 공개 범위

| 등급 | 누가 볼 수 있나 | 누가 설정할 수 있나 |
|------|-----------------|---------------------|
| 비공개 | 그룹 멤버만 | 일반 회원 |
| 운영진 공개 | 운영진만 | 운영진만 |
| 회원 공개 | KHLUG 회원 (재학·휴학·졸업) | 일반 회원 |
| 완전 공개 | 교류 회원 포함 모든 회원 | 일반 회원 |

### 공개 범위 + 특수 조직 이중 제한

- 그룹에 특수 조직(팀, 회사 등)이 지정되어 있으면, 공개 범위 조건을 만족하더라도 **해당 조직에 소속된 회원만** 열람 가능

## 3. 그룹 생명주기

### 상태

| 상태 | 설명 |
|------|------|
| 진행 중 | 활동 중인 그룹 |
| 중단 | 50일 이상 미활동으로 자동 전환되거나, 운영진이 수동 전환 |
| 종료(성공) | 목표를 달성하고 완료 |
| 종료(실패) | 목표를 달성하지 못하고 완료 |

### 상태 전이 규칙

- **진행·중단 → 종료(성공/실패)**: 그룹장 또는 운영진이 변경 가능
- **진행 → 중단**: 운영진만 수동 전환 가능. 또는 50일 미활동 시 자동 전환
- **중단 → 진행**: 그룹 내에서 아무 활동(카드 추가, 기록 작성 등)이 발생하면 **자동으로 복귀**
- **종료 → 진행**: 역전환 가능하지만, 종료 시 받았던 포인트가 회수됨
- **중단 설정은 운영진 전용** — 그룹장이라도 직접 중단시킬 수 없음
- **종료된 그룹의 조작 제한**: 활동에 따른 자동 복귀는 중단 상태에만 적용되며 종료 상태는 자동으로 진행 중이 되지 않음. 따라서 그룹을 진행 중으로 되돌리지 않는 변경 동작은 종료된 그룹에서 할 수 없음

### 자동 중단 규칙

- 매 시간 검사하여, 마지막 활동 이후 **50일**이 경과한 진행 중 그룹을 자동 중단 처리
- "활동"의 기준: 카드/기록 추가·삭제·복구, 순서 변경, 멤버 참여·탈퇴 등 대부분의 그룹 내 행위
  - 단, **그룹 정보 수정만으로는 활동으로 인정되지 않음**
  - 카드 레이블 변경, 카드·기록의 포트폴리오 포함 변경도 활동으로 인정되지 않음. 중단 상태를 해제하거나 최근 활동 일시를 갱신하지 않음

## 4. 그룹 관리 기능

### 4-1. 그룹 생성

- **누가**: 활성 회원 (재학·휴학·졸업 상태)
- **필수 정보**: 이름, 카테고리
- **선택 정보**: 목적, 관심 분야, 기술 스택, 참여 허용 여부, 공개 범위, 저장소 URL, 특수 조직
- **아이디어클라우드 연동**: 아이디어에서 그룹을 만들 수 있음. 연동 시 해당 아이디어는 만료 처리되고, 아이디어 작성자에게 알림 전송
- **포인트**: 생성자에게 +50 exp

### 4-2. 그룹 수정

- **누가**: 그룹장 (운영 카테고리 그룹은 운영진도 가능)
- **조건**: 진행 중 또는 중단 상태인 그룹만 수정 가능. 종료된 그룹은 수정 불가
- **알림**: 변경된 항목에 대해 그룹 멤버 전체에 알림

### 4-3. 그룹 목록 조회

- **내 그룹**: 내가 참여 중인 그룹 목록
- **프로그램**: 교육·프로그램·운영 카테고리 그룹
- **연구**: 스터디·프로젝트·문서화 카테고리 그룹
- **관심 분야별**: 관심 분야 키워드로 필터링
- **조직별**: 특수 조직(팀/회사) 소속 그룹
- **키워드 검색**: 제목·목적·기술 스택에서 검색
- **성공 그룹**: 종료(성공) 상태 그룹만
- **진행 중 그룹**: 진행 중 상태 그룹만
- **회원별 참여 현황**: 활성 회원 중 진행 중 그룹 참여/미참여 분류

### 4-4. 그룹 상세 조회

- 공개 범위 및 특수 조직 기반 열람 권한 검증
- Discord 채널 연동 정보 표시 (채널 URL, 참여 여부)

## 5. 멤버 관리

### 5-1. 그룹 참여 (가입)

- **조건**: 참여 허용이 켜져 있고, 그룹 열람 권한이 있어야 함
- **포인트**: +40 exp
- **알림**: 본인에게 확인 알림, 그룹장에게 참여 알림 (운영 그룹은 전 멤버에게)

### 5-2. 그룹 탈퇴

- **조건**: 그룹 멤버여야 함
- **제한**: **운영 카테고리가 아닌 그룹에서 그룹장은 탈퇴할 수 없음** — 먼저 다른 멤버에게 그룹장을 위임해야 함
- **포인트**: -40 exp
- **알림**: 본인 + 그룹장 (운영 그룹은 전 멤버)

### 5-3. 멤버 내보내기 (강제 탈퇴)

- **누가**: 그룹장 (운영 카테고리 제외)
- **포인트**: 내보내진 멤버에게 -40 exp
- **알림**: 해당 멤버에게 알림

### 5-4. 그룹장 위임

- **누가**: 현재 그룹장만
- **조건**: 위임 대상은 기존 멤버여야 함
- **알림**: 멤버 전체에 알림

---

## 6. 칸반 보드 — 리스트

리스트는 칸반 보드의 열(column)에 해당합니다.

### 6-1. 리스트 추가

- **누가**: 그룹 멤버
- **입력**: 리스트 이름

### 6-2. 리스트 수정

- **누가**: 그룹 멤버
- **수정 가능 항목**: 이름, 설명

### 6-3. 리스트 삭제

- **누가**: 그룹 멤버
- **조건**: 리스트 안에 카드가 하나도 없어야 함

### 6-4. 리스트 순서 변경

- **누가**: 그룹 멤버
- **동작**: 드래그 앤 드롭으로 리스트 순서 재배치

---

## 7. 칸반 보드 — 카드

카드는 리스트 안에 속하는 작업 단위입니다.

### 7-1. 카드 추가

- **누가**: 그룹 멤버
- **포인트**: +1 ExPoint
- **알림**: 멤버 전체

### 7-2. 카드 수정

- **누가**: 그룹 멤버
- **수정 가능 항목**: 이름, 설명

### 7-3. 카드 순서 변경 및 리스트 간 이동

- **누가**: 그룹 멤버
- **동작**: 같은 리스트 내 순서 변경, 또는 다른 리스트로 이동 가능

### 7-4. 카드 아카이브 (삭제)

- **누가**: 그룹 멤버
- **동작**: 카드를 보드에서 제거 (소프트 삭제). 기록은 보존됨
- **포인트**: 카드 작성자에게 -1 ExPoint

### 7-5. 카드 복구

- **누가**: 그룹 멤버
- **동작**: 아카이브된 카드를 지정한 리스트로 복구
- **포인트**: +1 ExPoint

### 7-6. 카드 활성화/비활성화

- **누가**: 그룹 멤버
- **동작**: 비활성화해도 보드에서 숨기지 않고 비활성 상태로 표시. 재활성화 가능
- **제한**: 비활성 카드는 이름·설명·커버 이미지 수정과 기록 작성·수정·삭제·복구·이동·포트폴리오 포함 변경을 할 수 없음. 재활성화와 카드 삭제는 가능
- **알림**: 멤버 전체

### 7-7. 담당자 지정

- **누가**: 그룹 멤버
- **동작**: 카드에 담당자를 배정하거나 해제
- **알림**: 이전 담당자와 신규 담당자에게 각각 알림

### 7-8. 카드 이어받기

- **동작**: 다른 카드의 기록을 이어받는 연결 설정
- **조건**: 이어받는 카드의 기록이 **5개 미만**이어야 함
- **해제**: 이어받기 연결을 해제할 수도 있음

### 7-9. 카드 레이블

- **종류**: 빨강, 노랑, 초록, 파랑, 보라, 흰색, 회색, 검정 (8색)
- **동작**: 각 레이블을 독립적으로 켜고 끌 수 있음 (여러 레이블 동시 적용 가능)

### 7-10. 카드 기록 정렬 방향

- 카드별로 기록의 정렬 방향을 오름차순/내림차순으로 설정 가능

### 7-11. 카드 커버 이미지

- **동작**: 업로드한 이미지 또는 외부 이미지 URL을 카드의 대표 이미지로 지정하거나 제거할 수 있음

### 7-12. 카드 포트폴리오 포함

- 카드를 포트폴리오에 포함할지 여부를 토글

## 8. 칸반 보드 — 기록

기록은 카드 안에 작성되는 실제 활동 내용입니다.

### 8-1. 기록 작성

- **누가**: 그룹 멤버
- **내용**: 텍스트 + 파일 첨부 + 이미지 첨부
- **포인트**: 행위자에게 +2 exp
- **알림**: 멤버 전체
- **자동 저장**: 작성 중인 내용이 자동 저장되며, 최종 저장 시 삭제

### 8-2. 기록 수정

- **누가**: 기록 작성자 본인만 (특수 그룹 9477은 전 멤버 수정 가능)
- **수정 가능 항목**: 내용, 첨부 파일

### 8-3. 기록 삭제 (아카이브)

- **누가**: 그룹 멤버
- **동작**: 소프트 삭제
- **포인트**: 기록 작성자에게 -2 exp. 삭제 요청자가 작성자와 달라도 작성자에게 차감

### 8-4. 기록 복구

- **누가**: 그룹 멤버
- **포인트**: 행위자에게 +2 exp

### 8-5. 기록 이동

- **누가**: 그룹 멤버
- **조건**: 같은 그룹 내 다른 카드로만 이동 가능
- **조건**: 기록이 삭제 상태가 아니고, 카드가 비활성화 상태가 아니어야 함
- 현재 카드와 같은 카드로 이동하면 아무것도 바꾸지 않고 성공으로 처리

### 8-6. 기록 보관함

- 개인별로 마음에 드는 기록을 보관함에 저장할 수 있음
- 보관/해제 토글 방식

### 8-7. 기록 외부 임베드

- 게시판 등 외부에서 기록을 임베드할 수 있는 기능
- 그룹 열람 권한이 없으면 내용 대신 "접근 불가" 상태 반환

### 8-8. 기록 포트폴리오 포함

- 기록을 포트폴리오에 포함할지 여부를 토글
- 기록은 생성 시 **기본적으로 포트폴리오에 포함**됨

### 8-9. Slack 연동 기록 작성

- Slack에서 특정 회원 명의로 기록을 추가할 수 있음
- 일반 인증 없이, Slack 봇이 직접 호출하는 방식

---

## 9. 그룹 내 검색 및 아카이브 조회

### 9-1. 그룹 내 검색

- **대상**: 카드 이름 또는 기록 내용에서 키워드 검색
- **범위**: 해당 그룹 내로 한정

### 9-2. 아카이브 목록

- 아카이브(삭제)된 카드 목록을 조회하여 필요 시 복구 가능

---

## 10. 포트폴리오

- **발행**: 그룹장이 그룹 단위로 포트폴리오를 발행/취소할 수 있음
- **포인트**: 발행 시 멤버 전체 +10, 취소 시 -10 ExPoint
- **구성**: 포트폴리오가 발행된 그룹의 포트폴리오 포함 카드/기록이 외부에 공개됨
- **조회**: 포트폴리오 목록 페이지에서 발행된 그룹 목록을 볼 수 있음 (24개씩 페이지네이션)
- **공개 범위**: 포트폴리오 페이지는 별도 인증 없이 누구나 열람 가능

---

## 11. 세미나 시스템

### 11-1. 세미나 기수 관리

- **기수 추가**: 연도 + 학기(1학기/여름/2학기/겨울)로 구성
- **기수 삭제**: 운영진만 가능, 전년도 기수는 삭제 불가
- **접수 상태**: 접수 전 → 접수 중 → 접수 마감 순서로 전이. 마감 후 재오픈 가능
- **알림**: 접수 시작/마감 시 전체 회원에게 방송 알림 + Discord 채널 알림

### 11-2. 세미나 세션 등록/취소

- **누가**: 그룹장 (교류 회원 제외)
- **조건**: 접수 중 기간에만 등록/취소 가능
- **포인트**: 등록 시 멤버 전체 +150, 취소 시 -150 exp
- **알림**: 멤버 전체 + 운영진

### 11-3. 운영진 강제 제거

- **누가**: 운영진
- **동작**: 세미나 세션에서 그룹을 강제 제거
- **포인트**: 멤버 전체 -150 exp

## 13. 활동 로그
