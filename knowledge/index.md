- [그룹 페이지 개발 원칙](frontend/group/principles.md): 구조 변경 제안, 도메인 상태 격리와 공개 인터페이스, 조작 성능의 판단 기준.
- [그룹 페이지 정책](frontend/group/policies.md): 창 상태전이·패치·배치, 공개 인터페이스, 페이지 상태 등 구현 시 사용할 파일과 확장 방법.
